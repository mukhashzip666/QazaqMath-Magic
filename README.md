# QazaqMath-Magic

**«Сиқырлы кесте» — Магиялық математикалық фокус және ЖИ-зертхана**  
*(Интерактивная образовательная платформа угадывания чисел на основе двоичной системы счисления и степеней числа 2)*

---

## ✨ Жоба туралы / О проекте

**QazaqMath-Magic («Сиқырлы кесте»)** — оқушылар мен студенттерге екілік санау жүйесін (`0` мен `1`) және 2 санының дәрежелерін ($2^0=1, 2^1=2, 2^2=4, 2^3=8, 2^4=16, 2^5=32$) интерактивті математикалық фокус және **Виртуалды Сиқыршы (ЖИ-көмекші)** арқылы түсіндіретін білім беру веб-қосымшасы.

### Негізгі мүмкіндіктері:
- 🎩 **Сиқырлы фокус (4 деңгей):** `1–10`, `1–15`, `1–31` (классикалық 5 баған) және `1–63` (шебер деңгейі, 6 баған).
- 🤖 **Виртуалды Сиқыршы (ЖИ чат-көмекшісі):** ойлаған санды табады, оның математикалық формуласын ашады және кез келген санды екілік кодқа жіктеп береді.
- 💡 **Интерактивті 5-биттік шамдар зертханасы:** биттерді қосып/өшіру арқылы сандардың қалай түзілетінін нақты уақытта зерттеу.
- 🏆 **«1-ден 10-ға дейін» Білім тесті:** 10 сұрақтан тұратын интерактивті викторина (10/10 балдық шкаламен).
- 🎓 **Жоба паспорты:** ғылыми жобаны қорғауға арналған дайын құрылым (өзектілігі, мақсаты, міндеттері, болжамы, қорытындысы) және бір кликпен автономды HTML-файлды жүктеу.

---

## 🚀 Іске қосу / Запуск проекта

### 1-тәсіл: Сервермен толық іске қосу (React + Express + TypeScript)
```bash
npm install
npm run dev
```
Браузерде ашыңыз: `http://localhost:3000`

### 2-тәсіл: Автономды HTML-файл (серверсіз)
Жоба қалтасындағы `Сиқырлы-кесте-Жоба.html` файлын кез келген браузерде екі рет басып ашыңыз.
