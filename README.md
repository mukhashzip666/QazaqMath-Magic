# ✨ QazaqMath-Magic — «Сиқырлы кесте»

**«Сиқырлы кесте» — Магиялық математикалық фокус және ЖИ-зертхана**  
*(Интерактивная образовательная веб-платформа математического фокуса на основе двоичной системы счисления и степеней числа 2)*

---

## 📌 Жоба туралы / О проекте

**«Сиқырлы кесте» (QazaqMath-Magic)** — оқушылар мен студенттерге информатика мен дискретті математиканың іргетасы саналатын **екілік санау жүйесін (`0` мен `1`)** және **2 санының дәрежелерін** ($2^4=16, 2^3=8, 2^2=4, 2^1=2, 2^0=1$) көрнекі математикалық фокус және **Виртуалды ЖИ-Сиқыршы** арқылы түсіндіретін заманауи білім беру веб-қосымшасы.

Пайдаланушы 1 мен 31 аралығындағы кез келген санды ойлап, ол кездесетін бағандарды (1–5) белгілейді, ал жүйе ойлаған құпия санды бірден тауып, оның математикалық формуласын көрсетеді.

---

## 🧩 Қосымша бөлімдері мен функциялары / Разделы и функции

Барлық негізгі функциялар жоғарғы навигациялық панельде және жеке беттерде орналасқан:

1. **📋 Сиқырлы кесте (Главная страница фокуса)**
   - Классикалық 5 бағандық кесте (1–31 сандары).
   - Бағандарды интерактивті таңдау, құпия санды лезде табу («Құпия санды айту») және қосынды формуласын шығару.
   - Қосымша беттерге жылдам өту батырмалары.

2. **🤖 Виртуалды Сиқыршы & Фокус құпиясы (ИИ-Фокусник и разбор секрета)**
   - **ЖИ Чат-көмекшісі (Google Gemini API + локалды интеллектуалды база):** қазақ тілінде сұрақтарға жауап береді, кез келген санды екілік кодқа жіктейді.
   - **Фокустың математикалық құпиясы:** екілік разрядтар мен салмақтар кестесі (`16, 8, 4, 2, 1`), интерактивті биттерді қосу/өшіру.
   - **4 күрделілік режимі:** `1–10` (4 баған), `1–15` (4 бит), `1–31` (5 баған — классика), `1–63` (6 баған — шебер деңгейі).

3. **💡 Теория мен зертхана (Теория и интерактивная лаборатория)**
   - **5-биттік шамдар зертханасы:** шамдарды қосу (`1`) және өшіру (`0`) арқылы екілік кодтың ондық санға қалай айналатынын нақты уақытта бақылау.
   - **Математикалық теорема және дәлелдеме:** $N = b_4 \cdot 16 + b_3 \cdot 8 + b_2 \cdot 4 + b_1 \cdot 2 + b_0 \cdot 1$.
   - **Тарихи шолу:** Г. В. Лейбниц, Дж. Буль, К. Шеннон және заманауи ІТ-технологиялардағы қолданысы.

4. **🏆 Білім тесті 10/10 (Интерактивная викторина)**
   - 10 сұрақтан тұратын білімді тексеру тесті.
   - Әр сұраққа толық математикалық түсіндірме және 10 балдық шкала бойынша қорытынды бағалау.

5. **🎓 Жоба паспорты (Паспорт научного проекта)**
   - Ғылыми жобаны қорғауға арналған дайын құрылым: *өзектілігі, мақсаты, міндеттері, болжамы мен жаңалығы, қорытындысы*.
   - Автор мен жетекші деректерін өңдеу, басып шығару (`Print`) және **бір кликпен автономды HTML-файл етіп жүктеу**.

6. **🪄 Қосымша құралдар (Быстрые инструменты в шапке)**
   - **Сандар тренажері:** 1–31 аралығындағы кез келген санның қай бағандарда орналасқанын және екілік кодын жылдам көру.
   - **Ойын ережесі:** 3 қадамдық нұсқаулық.
   - **Дыбыстық эффектілер:** Web Audio API негізіндегі интерактивті дыбыстар (қосу/өшіру мүмкіндігімен).
   - **📱 Мобильді адаптация:** смартфондар мен планшеттерге толық бейімделген интерфейс.

## 🛠 Технологиялық стек / Стек технологий

- **Frontend:** React 19, TypeScript, Tailwind CSS 4, Lucide Icons
- **Backend / API:** Node.js, Express, `@google/genai` (Gemini API), Vercel Serverless Functions (`api/magician/chat.ts`)
- **Сборка:** Vite 6, `tsx`

## 🚀 Іске қосу / Запуск проекта

### 1. Тәуелділіктерді орнату / Установка зависимостей
```bash
npm install
```

### 2. Орта айнымалыларын баптау (міндетті емес) / Настройка `.env` (опционально)
ЖИ-сиқыршы Google Gemini API арқылы жұмыс істеуі үшін `.env` файлына кілтті қосуға болады (кілт болмаған жағдайда кіріктірілген локалды интеллектуалды модуль автоматты түрде іске қосылады):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Жобаны іске қосу / Запуск сервера разработки
```bash
npm run dev
```
Браузерде ашыңыз: [http://localhost:3000](http://localhost:3000)

### 4. Продакшн жинақтау / Сборка для продакшна
```bash
npm run build
```

### 5. Автономды HTML-нұсқа (серверсіз) / Автономная HTML-версия
Жоба түбіріндегі `Сиқырлы-кесте-Жоба.html` файлын интернетсіз және серверсіз кез келген браузерде тікелей ашуға болады.
